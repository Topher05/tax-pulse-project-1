# Team Ticket Journal

This folder keeps a shared implementation journal for Jira-ticket work tracked in
`planning/stackpulse_tax.csv`.

Use `ticket-journal.md` to connect each ticket to the code that was changed. Each entry
should use the current branch name as its naming source, with the ticket identifier at
the end of the branch name, such as `martins-okorie-jira43`. The entry should briefly
capture the branch, assignee, Jira key, summary, description, acceptance criteria,
implementation notes, project scope connection, changed files, and validation results.

The journal is meant to help the team explain not just what changed, but why the change
matches the ticket.
