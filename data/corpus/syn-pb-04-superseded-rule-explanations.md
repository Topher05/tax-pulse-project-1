# SYN-PB-04 Client Explanation Playbook for Superseded Rules and Effective Dates

This document is synthetic training content from the fictional Northstar Synthetic Tax Planning Authority. All rates, thresholds, dates, and limits in this document are invented and must not be treated as real tax law.

## SYN-PB-04-a Explaining a superseded rule

When a retrieved rule is superseded, explain that the planning system found an older synthetic provision and that the recommendation must use the rule effective for the scenario date. The explanation should cite both the older section and the replacement when both are relevant.

The explanation should avoid blaming the advisor or the system. It should say that the recommendation needs a date-specific citation because the corpus contains both historical and current synthetic provisions.

### SYN-PB-04-b Effective-date wording

Use date-first language: "For scenarios before 2026-01-01, the old synthetic credit applied; for scenarios on or after 2026-01-01, the replacement synthetic credit applies." Do not imply that either provision is real law.

Date-first wording helps retrieval distinguish effective-date questions from general retirement contribution questions. It also keeps client-facing summaries from overemphasizing section labels.

## SYN-PB-04-c Reviewer resolution procedure

If an advisor cites SYN-TC-4310-a for a current scenario dated after 2026-01-01, return the recommendation for revision and request a citation to SYN-TC-4310-b.

If the advisor cites only SYN-TC-4310-b for a historical scenario before 2026-01-01, request the same kind of revision in the other direction. The reviewer should name both the incorrect citation and the expected citation.

### SYN-PB-04-d Audit-note convention

The audit note should identify the section ID, document title, and synthetic issuer. It should not paraphrase the superseded provision in a way that removes the effective date.

The audit note may include a short reason such as "replacement provision applies to the recommendation date." It should not copy large passages from the source document.
